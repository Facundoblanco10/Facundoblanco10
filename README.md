## 🧠 How I think about software

I care more about **how systems are built** than the specific technologies used.

Some principles I follow:

- **Clarity over cleverness**  
  Code should be easy to read, not impressive.

- **Scalability is a design decision**  
  Not something you “add later”.

- **Consistency beats perfection**  
  A consistent codebase is easier to maintain than a “perfect” one.

- **Backend first mindset**  
  Strong foundations make everything else simpler.

- **Avoid unnecessary complexity**  
  If it can be simple, it should be simple.
